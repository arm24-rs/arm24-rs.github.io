How it works

Working with me

Contact is by email and phone.

Written offer first

Before any work you get a written offer with scope, deadlines and price. The offer is free and without obligation.

Handover

You receive the source code and a short written note on each change while the work goes on, not only at the end, so another developer can continue if I am unavailable.

On delivery you receive the source code with its automated tests, the documentation and the access needed to run and maintain the software, and a user manual where the software has end users. Another firm can take over the maintenance. Support after delivery is agreed in the offer.

The software runs on your server or in the cloud you choose.

Terms

The start date and the schedule are fixed in the offer. A larger job can be delivered in stages agreed in the offer, each of them usable on its own.

Contracts in English, invoices in EUR. Time zone: Central European Time (CET/CEST). A confidentiality agreement can be signed before work starts.

AI and your data

I work with Claude Code, an AI coding tool by Anthropic (USA). I plan every change and check the result myself. The tool works on a development copy with test data: it gets source code and task descriptions, while your production database, personal data and passwords stay outside it.

Anthropic processes the code in the USA and other countries. The setting that lets it train its models on the code is switched off in my account.
