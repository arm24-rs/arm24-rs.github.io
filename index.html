AI in practice

Not a buzzword for us: AI runs in production systems we built, and in the way we build them.

AI agents in products

A WhatsApp message-template agent on Gemini: a user describes what they need and gets a template that passes Meta review in a few clicks. Includes Meta rejection rules, per-conversation cost caps and model benchmarking.

MCP integrations

Model Context Protocol server that lets AI assistants work with a messaging platform’s data and APIs securely, with proper authentication scopes.

AI-assisted delivery

An agent workflow that takes a ticket from plan to tested pull request with two or three human messages, plus an automated reviewer that checks pull requests against the ticket and a checklist. A human engineer reviews every change.
