How ARM24 works

One accountable senior engineer. AI agents do much of the routine work; he plans, checks and signs off every step.

Plan before code

Every task starts with a written plan: what changes, what it affects, how it will be checked. Independent AI reviews challenge the plan, and work starts only after it is approved.

AI-assisted delivery

An agent workflow takes a task from plan to tested change, and an automated reviewer checks the result against the task and a checklist. The engineer reviews every change before it ships.

Production experience

Since 2021: releases, on-call and incident investigation on a platform in daily production use. Earlier: a market surveillance system for financial institutions.
